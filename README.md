# Advanced Calculator

A public-facing, standalone scientific calculator built with HTML, CSS, and JavaScript.

## Features
- Scientific functions (sin, cos, tan, log, ln, sqrt, etc.)
- Degree/Radian mode
- Memory functions (MC, MR, M+, M-)
- Calculation history
- Keyboard support
- Responsive UI

## Run locally
Open `index.html` in a browser.

## GitHub Pages
This project is designed to work well as a static site. You can deploy it using GitHub Pages from the repository root.
